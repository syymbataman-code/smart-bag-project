SMART BAG — ғылыми жоба сайты
================================

Файлдар:
- index.html — сайттың мазмұны
- style.css — дизайн және бейімделгіш көрініс
- script.js — интерактивті зертхана

Жергілікті түрде ашу:
1. ZIP файлын компьютерге жүктеп, ішін шығарыңыз.
2. index.html файлын браузерде ашыңыз.

Интернетке жариялау (GitHub Pages):
1. GitHub.com сайтына кіріп, аккаунт ашыңыз/кіріңіз.
2. New repository арқылы жаңа репозиторий жасаңыз (мысалы, smart-bag-project).
3. index.html, style.css және script.js файлдарын жүктеңіз.
4. Repository → Settings → Pages бөліміне өтіңіз.
5. Build and deployment: Deploy from a branch; Branch: main, folder: /(root) таңдаңыз да Save басыңыз.
6. Бірнеше минуттан кейін Pages бөлімінде жарияланған сайттың сілтемесі пайда болады.

Ескерту:
- Бұл — жұмыс істейтін интерактивті веб-демонстрация, бірақ нақты сөмкеге қосылған датчиктерден дерек алмайды.
- GPS Lab-та нақты орналасу көрсетілмейді; координаттар үлгі ретінде берілген.
- Салмақ есептеуіндегі 15% — жобалық демонстрациялық жорамал, әмбебап медициналық норма емес.
- Сайтты интернетке жариялағаннан кейін GitHub Pages берген сілтемені қазылар алқасына көрсетуге болады.
